> **Note:** The legacy `org.aesh.graphics` package was removed in 3.17.5. For terminal rendering, use the [Charts module](/docs/aesh/charts) which provides line charts, bar charts, and sparklines with a modern `Canvas` abstraction. For lower-level display needs, use the utility classes described below.

## Display Utilities

Aesh provides several terminal display utilities in the `org.aesh.util` package:

- **[Table](/docs/aesh/table)** -- render tabular data with borders and column alignment
- **[Tree](/docs/aesh/tree)** -- render tree structures
- **[Progress Bar](/docs/aesh/progress-bar)** -- show progress indicators
- **[Graph](/docs/aesh/graph)** -- render directed acyclic graphs (DAG)

For charting and data visualization, see the [Charts module](/docs/aesh/charts).
