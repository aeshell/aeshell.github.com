Æsh Readline is a library for handling console input with the goal to support most GNU Readline features.

## Overview

Æsh Readline provides readline functionality used by the Æsh project. It offers comprehensive terminal input handling with support for editing modes, history, completion, and remote connections.

## Key Features

- Line editing with undo/redo support
- History (search, persistence)
- Tab completion
- Password masking
- Paste buffer
- Emacs and Vi editing modes
- Cross-platform (POSIX and Windows)
- Configurable history file & buffer size
- Standard out and standard error support
- Redirect, alias, and pipeline support
- Remote connectivity (SSH, Telnet, WebSockets)
